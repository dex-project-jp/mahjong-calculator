# 麻雀点数計算 v1.0

日本式リーチ麻雀の4人打ち用PWA。通常手の符、七対子25符／50符、符・翻数の直接指定に対応。

## 起動

Node.jsはテスト用。アプリは依存ライブラリなしの静的ファイルです。

```sh
python3 -m http.server 8000
node --test
```

ローカルでは http://localhost:8000 を開きます。iPhoneではHTTPSで公開したURLをSafariで開き、共有メニューの「ホーム画面に追加」を選びます。更新を配信する際は sw.js のキャッシュ名を変更します。

## 設定と前提

- 連風牌4符、数え役満あり、切り上げ満貫なしが初期値です。七対子は25符です。
- ロン完成の刻子は明刻の符を使います。門前ロンの10符は副露の有無で判定します。
- 役・ドラ・和了の合法性はユーザーが確認します。役満は倍率を直接指定します。
- 三麻、包、複数人の同時和了、嶺上開花のツモ符を除外するローカルルールは対象外です。
